四步上手

克隆仓库

下载或 git clone 本项目到本地任意目录。

打开扩展管理

地址栏访问 chrome://extensions/。

开启开发者模式

右上角切换"开发者模式"开关。

加载扩展

点击"加载已解压的扩展程序"，选择项目根目录即可。
