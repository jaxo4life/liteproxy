## 🌐 LiteProxy — 简洁高效的 Chrome 代理扩展

**LiteProxy** 是一款轻量、易用的 Chrome 浏览器代理扩展，支持 **HTTP** 和 **SOCKS5** 协议，基于 **Manifest V3** 规范开发。  
无需复杂设置，几步即可完成代理切换，让你的浏览体验更加自由顺畅。  

---

### ✨ 功能特点
- 📦 **轻量无依赖**：仅需加载扩展，无需安装额外软件。  
- 🌍 **双协议支持**：兼容 **HTTP** 和 **SOCKS5** 代理。  
- ⚡ **即时切换**：一键启用/禁用代理，立即生效。  
- 🔒 **安全设计**：基于 **Manifest V3**，更高安全性与性能。  
- 🇨🇳 **内置中国大陆直连规则**：常见国内网站自动直连，海外流量走代理，智能又省心。  

---

### 📥 安装方法

1. **下载项目文件**  
   将本仓库代码下载并解压至本地，如解压到 `liteproxy` 文件夹。

2. **打开 Chrome 扩展管理**  
   在 Chrome 浏览器中输入：  
```

chrome://extensions/

```

3. **启用开发者模式**  
右上角开启 **开发者模式**。

4. **加载已解压的扩展**  
点击 **"加载已解压的扩展程序"**，选择 `liteproxy` 文件夹。  

5. **开始使用**  
点击扩展图标，配置代理地址和端口，选择协议，即可启用代理。

### 💡 使用建议
- 如果你的代理需要账号密码，可以在 `host:port` 前加上认证信息，例如：
```

username\:password\@host\:port

```
- 建议在需要访问外网时开启代理，不使用时关闭，以减少不必要的流量消耗。
